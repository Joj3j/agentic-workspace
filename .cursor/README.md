# .cursor

Cursor config for the workspace.

- **rules/** — Workspace-wide and language rules (Go, Rust, Java, etc.).
- **commands/** — Custom commands (e.g. `mr`).
- **skills/** — Agent skills (e.g. maintain-workspace-rules, create-repo-arch-doc). See each skill’s `SKILL.md`.
- **scripts/** — Helper scripts (e.g. Confluence create-page). See `scripts/README.md`.
